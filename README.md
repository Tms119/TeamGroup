# TEAM Group

Corporate website for TEAM Group, a Bangladesh-based conglomerate spanning manufacturing, apparel, pharmaceuticals, real estate, and technology.

**Live:** https://team-group-two.vercel.app

---

## Stack

- **Frontend:** Semantic HTML5, CSS3 (modern design tokens and CSS variables), Vanilla JavaScript
- **Animations:** Canvas and video frame-sequence scroll controller, custom cursor interaction
- **Deployment:** Vercel

---

## Features

- High-performance canvas-based frame scroll playback synced to scroll position
- Custom cursor with hover states and magnetic snap interactions
- Responsive multi-industry business portfolio showcase
- Zero-dependency architecture with sub-second initial load

---

## Run Locally

```bash
git clone https://github.com/Tms119/TeamGroup.git
cd TeamGroup
# open index.html in your browser, or run a local static server:
npx serve .
```
